# 👥 Team Availability Tracker

A web application for tracking and managing team member availability in real time.

## 🚀 Overview

The Team Availability Tracker helps teams record and view the availability status of their members through a simple web interface.

## ✨ Features

- 👥 Team member management
- 🟢 Availability status tracking
- 🔄 Dynamic status updates
- 💾 Local data persistence
- 📱 Simple and responsive interface
- ⚡ Node.js and Express backend

## 🛠️ Tech Stack

- JavaScript
- Node.js
- Express.js
- HTML
- CSS
- SQLite
